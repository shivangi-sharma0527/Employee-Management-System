# Employee Management System — HTML, CSS & JavaScript

A professional frontend Employee Management System built using only HTML, CSS and vanilla JavaScript.

## Features
- Sign Up and Sign In
- Session-based protected dashboard
- Login / Sign Up with authenticated access
- Employee CRUD (Add, Edit, Delete, Search and Filter)
- Search and filters
- Department management
- Dashboard statistics and department chart
- Employee reports and CSV export
- Dark mode
- Responsive UI
- LocalStorage data persistence

## Run
No server or installation is required.

1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Create an account from **Sign Up**.
4. Any authenticated account can add, edit, delete, search, and manage employee records.
## Note
This version is intentionally frontend-only. Authentication and data are stored in browser storage, so it is suitable for a college/internship demo. For a production application, connect the UI to a backend API and database.


## Authentication
Click **Create Account**, enter a name, email, and password, and submit the form. The account is stored in the browser's `localStorage`. Then sign in with the same credentials. This is a frontend demo; it is not production-grade authentication.
